Panduan Lengkap: Cara Memasang Processor AMD AM5 dengan Benar & Aman

INTRO

Pengantar

Socket AM5 menggunakan desain LGA (LGA 1718) — pin emas ada di motherboard, bukan di CPU. Jangan sentuh atau tekan area pin sama sekali. Kerusakan pin dapat merusak board secara permanen.

Langkah 1

Buka Tuas Pengunci Socket Motherboard

  1. Letakkan motherboard di permukaan anti-statis yang datar.
  2. Cari tuas logam (retention arm) di sisi socket AM5.
  3. Tekan tuas ke bawah sedikit lalu geser ke samping untuk melepas dari kait pengaman.
  4. Angkat tuas vertikal hingga membentuk sudut ±135° dari motherboard.
!

Jangan pernah memaksakan CPU masuk sebelum tuas terbuka penuh — tekanan berlebih dapat membengkokkan pin LGA.

Langkah 2

Orientasi & Penempatan CPU (Notch Alignment)

  1. Pegang CPU hanya di tepi samping — jangan sentuh die (chip) atau bagian bawah yang berlapis kontak.
  2. Cari tanda segitiga emas kecil di salah satu sudut CPU dan di sudut socket motherboard.
  3. Sejajarkan kedua segitiga tersebut sebelum menurunkan CPU.
  4. Turunkan CPU secara vertikal dan perlahan — CPU harus jatuh masuk ke socket dengan sendirinya tanpa tekanan apapun.
💡

Jika CPU tidak mau masuk, jangan dipaksa. Angkat kembali, periksa orientasi segitiga, dan coba lagi.

Langkah 3

Kunci Tuas & Verifikasi Pemasangan

  1. Setelah CPU masuk, turunkan tuas kembali ke posisi horizontal.
  2. Tekan tuas ke bawah hingga terkunci di bawah kait plastik — kamu akan merasakan sedikit resistensi, ini normal.
  3. Resistensi ini disebabkan retention frame menekan IHS CPU agar kontak penuh dengan socket.
  4. Pastikan tuas terkunci rapat sebelum memasang cooler atau menyalakan PC.
!

Jika PC tidak booting dan LED CPU merah menyala, cek kembali apakah tuas sudah terkunci penuh di bawah kait plastik.

Langkah 4

Troubleshooting — LED CPU Merah / Tidak Booting

  1. Matikan PC dan cabut kabel power dari stopkontak sebelum membuka casing.
  2. Cek apakah tuas pengunci socket sudah terkunci penuh di bawah kait plastik.
  3. Verifikasi CPU kompatibel dengan socket AM5 motherboard — Ryzen 7000, 8000G, atau 9000 series.
  4. Periksa konektor power 8-pin ATX CPU (bukan 24-pin) sudah terpasang penuh di board.
💡

Jika menggunakan CPU baru di board lama, update BIOS dulu menggunakan CPU lama yang sudah kompatibel.

!

Jika ada pin socket yang bengkok, jangan coba perbaiki sendiri — bawa ke teknisi. Kerusakan pin AM5 umumnya memerlukan penggantian motherboard.
